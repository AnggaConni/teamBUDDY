# teamBUDDY

An original browser-based game project evolving toward a low-poly top-down action RPG that blends village life, farming, dungeon exploration, ecology, and global foodways.

## Experimental action RPG prototype

A separate combat sandbox is available at [prototype/action-rpg.html](prototype/action-rpg.html). It currently includes:
- Top-down 3D low-poly environment built with Three.js
- Continuous movement and camera follow
- Normal attack, heavy attack, dodge, nature-pulse skill, and potion
- Basic slime enemies, HP, drops, and pickup interactions
- Desktop keyboard/mouse controls and mobile joystick/action buttons

Open the HTML file through a local static server or GitHub Pages preview. The prototype loads Three.js from a CDN and requires a modern WebGL-enabled browser. This is an experimental prototype, not yet integrated into the existing game in index.html.

## Direction

The intended original game combines:
- Action RPG combat and dungeon progression
- Farming, crafting, cooking, and village economy
- NPC quests and relationships
- Environmental restoration and culturally grounded foodways
- Desktop and mobile browser support

Rune Factory is a genre reference only. teamBUDDY does not use Rune Factory code, characters, or assets.
